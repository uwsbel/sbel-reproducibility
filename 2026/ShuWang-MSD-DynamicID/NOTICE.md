# Notice

- **Code, scripts and data.** All code and scripts in this repository were written by the authors, except the Chrono data files listed below. All data are simulated; they were generated by the authors with the models described in the paper.
- **Project Chrono.** The three models are Project Chrono models. The HMMWV and the Polaris RZR are Chrono::Vehicle models. Their stock geometry is defined by the vehicle data files of Chrono, distributed with Chrono under its BSD 3-Clause license (Copyright (c) 2016, Project Chrono Development Team). The `geometry/` folders name the Chrono files that define the true geometry and give their SHA-256 values.
- **Chrono data files in this repository.** `hmmwv/code/chrono_data/` and `polaris/code/chrono_data/` hold the Chrono vehicle data files that the models read (suspension, steering, driveline, wheel, brake, chassis and tire files; no meshes), with the Chrono license in `chrono_data/LICENSE`. They are unchanged, except `Polaris_TMeasyTire_fixed.json`. That file is `Polaris_TMeasyTire.json` with the rolling resistance written as a list and a roundness entry added, so that the tire reader of the Chrono build accepts it.
- **Terrain query.** The rough-road terrain of the vehicle cases is queried through a small C++ helper compiled against Chrono. Its source and a build note are in `<case>/code/terrain/`. No binary is included.
- **PUMA-560.** The nominal dimensions and parameters of the reduced PUMA-560 model follow the PUMA-560 consensus model carried by the Robotics Toolbox for Python of P. Corke (`roboticstoolbox/models/DH/Puma560.py`).
- **Third-party packages.** PyChrono and the Python packages named in `ENVIRONMENT.md` are used under their own licenses and are not redistributed here.
